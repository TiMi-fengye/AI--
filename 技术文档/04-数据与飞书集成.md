# 04 数据、微信登录与飞书通知

> 历史说明：微信及飞书登录已取消，飞书仅保留需配置的业务通知。当前账号、数据范围和存储行为以 [架构 HTML](../人力资源管理系统开发架构.html)、[07-手机号账号与数据权限](./07-手机号账号与数据权限.md) 和实际代码为准；下文旧登录集成描述不再适用。

> 当前版本已停用飞书绑定、飞书 OAuth 登录和飞书工作台免登，人员快照中的飞书身份字段已清理。飞书应用消息通知配置仍可保留；登录改为微信扫码 OAuth，需配置微信开放平台网站应用凭据后启用。

## 1. 数据持久化模型

浏览器使用 `localStorage` 保存当前工作副本；参考部署以 MySQL `hr_system.system_snapshots` 表保存共享快照，`server/data/snapshot.json` 仅用于初始化和灾备。快照字段名称与前端导出格式如下：

| 字段 | 类型 | 说明 |
|---|---|---|
| `employees` | array | 人员、楼栋、部门、岗位、状态、入离职日期 |
| `attendance` | array | 日期、员工 ID、签到、签退和考勤状态 |
| `leaveRequests` | array | 请假类型、员工、日期、时长、审批状态和费用 |
| `overtime` | array | 加班类型、员工、日期、小时、审批状态和费用 |
| `settlements` | array | 月份、员工费用、加班费、请假扣款和合计 |
| `departments` | array | 部门名称 |
| `orgStructure` | object | 组织树（导入时支持） |
| `updateLogs` | array | 人员信息新增、修改、删除记录 |
| `performance` | array | 绩效记录 |
| `exportedAt` | string | 快照生成时间 |

MySQL 是参考部署的共享数据源，JSON 快照用于初始化和灾备；浏览器 Local Storage 是访问设备的本地副本。更换浏览器前应从系统管理中导出数据，或确认服务器快照已存在。

## 2. 关键业务字段

### 人员

常用字段：`id`、`name`、`department`、`position`、`company`、`building`、`status`、`joinDate`、`leaveDate`、`phone`、`email`。飞书绑定字段已从人员数据中删除。

### 加班

`overtimeType`：

- `fee`：费用加班，进入费用结算。
- `compensatory`：调休加班，只进入调休余额，不进入工资结算。

### 请假

`type`：

- `compensatory`：调休请假，扣减调休余额，不产生请假扣款。
- `leave`：普通请假，按配置计算请假扣款。
- `shift`：替班请假，仅允许外包单位外派人员使用，不产生请假扣款。

## 3. 结算逻辑

月度结算只统计已批准的费用加班和普通请假：

```text
费用合计 = 费用加班费 - 普通请假扣款
```

调休余额按员工累计计算：

```text
剩余调休时长 = max(0, 已批准调休加班时长 - 已批准调休请假时长)
```

费用加班不会计入调休时长；调休加班的 `otPay` 为 0；调休请假和替班请假的 `lvDeduct` 为 0。

## 4. 微信扫码登录

1. 管理员在“系统设置”填写微信 AppID、AppSecret、回调地址，并启用微信登录。
2. 登录页请求 `/api/wechat/auth-url`，服务端生成 10 分钟有效的一次性 `state`。
3. 浏览器打开微信开放平台二维码授权页。
4. 微信回调 `/api/wechat/callback?code=...&state=...`。
5. 服务端调用微信 `sns/oauth2/access_token` 和 `sns/userinfo` 获取 OpenID、UnionID、昵称和头像。
6. 回调页通过 `postMessage` 将已校验身份返回登录页。
7. `Auth.loginWithWechatProfile()` 查找 `wechatOpenId/wechatUnionId`；启用自动建号时才创建新系统账号。

微信登录使用 `snsapi_login` 网站扫码流程。系统不会读取或保存微信密码，也不会把 AppSecret 返回浏览器。

## 5. 飞书通知

请假和加班申请可以通过 `/api/feishu/send` 发送文本消息。服务端使用 `tenant_access_token` 调用 `POST /open-apis/im/v1/messages`。接收对象配置在 `server/config.json` 或系统设置中：

```json
{
  "receiveId": "oc_xxx 或 ou_xxx",
  "receiveIdType": "chat_id 或 open_id/user_id/union_id/email"
}
```

群聊使用 `chat_id`；用户单聊使用对应的用户 ID 类型。机器人必须在群聊中且应用可见范围包含接收用户。

## 6. 微信和飞书平台配置清单

### 微信开放平台

当前公网部署地址为 `http://YOUR_ECS_IP`。网站应用需要配置：

| 配置项 | 值 |
|---|---|
| 授权回调域名 | `YOUR_ECS_IP`（生产环境建议使用 HTTPS 域名） |
| OAuth 回调地址 | `http://YOUR_ECS_IP/api/wechat/callback` |
| 授权范围 | `snsapi_login` |

### 飞书消息通知

如需继续发送飞书请假/加班通知，在飞书开发者后台完成以下配置：

| 配置项 | 值 |
|---|---|
| 消息权限 | `im:message` 或后台显示的“获取与发送单聊、群组消息” |

消息 API 的权限和 `tenant_access_token` 要求参考飞书官方[消息 API 概述](https://open.feishu.cn/document/uAjLw4CM/ukTMukTMukTM/reference/im-v1)。

## 7. 配置验证

系统管理员登录后进入“系统设置”，检查：

1. 微信 AppID/AppSecret 已保存，AppSecret 输入框不会回显。
2. 微信登录已启用，自动创建账号按需要开启。
3. 微信回调域名与系统中的完整回调地址一致。
4. 飞书通知接收对象 ID 和类型匹配（如继续使用通知）。
5. 登录页显示“使用微信扫码登录”，不再显示飞书登录按钮。

不要在文档、工单或截图中记录 AppSecret/App Secret。若 Secret 泄露，应立即在对应平台重置并更新服务器配置。
