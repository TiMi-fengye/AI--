01

访问与交互

HTML / CSS / JavaScript

电脑和手机浏览器运行页面；App 调度业务模块，Store 同步当前账号范围内的数据。 启动时并发读取快照与组织配置；内存副本仅复制容器，避免重复序列化大附件，权限查询只读取目标人员楼栋。

02

入口与进程

Nginx / systemd

Nginx 转发请求至本机 Node 服务；systemd 负责开机启动、异常拉起和日志。 公开静态资源支持 ETag 重验证、304 与 gzip；人员和认证 API 保持 no-store。

03

认证与业务接口

Node.js / Cookie session

Node 内置 HTTP 服务托管页面；认证服务校验账号、会话和数据范围，楼长名单按当前账号角色与负责楼栋生成；人员导出只读接口从最新快照按管理员或楼长范围返回字段白名单。短信开关启用后增加注册与手机号登录验证码校验。

04

持久化与集成

MySQL / JSON / 阿里云短信 / 飞书 API

业务、账号和组织配置分别持久化；飞书用于业务消息。阿里云短信适配器已开发，开通签名、模板及服务凭据后启用。

05

独立root私有工具每天北京时间02:00在线备份实际生产程序、MySQL、运行文件及配置。按完成时间戳保存，稳定窗口和归档完整性通过才发布，保留全部成功备份；已安装且实际systemd服务试运行校验成功。
