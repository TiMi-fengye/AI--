# AI查询与周期报表

2026-11-24开发更新。已实现授权数据查询、月度/季度/年度事实报表、可选AI解读和管理员服务配置。本次功能仍待按固定版本发布到生产，真实模型尚未连接验证；开发测试通过不表示线上AI已经启用。

## 使用入口与权限

发布完成并重新登录后，从侧边栏进入 **AI 查询与报表**。

| 账号角色 | 查询与报表范围 | AI服务配置与连接测试 |
| --- | --- | --- |
| 管理员 | 全部授权人员及关联考勤、加班、请假数据，可进一步筛选 | 可使用 |
| 楼长 | 当前负责楼栋关联人员及对应业务数据，可进一步筛选 | 不可使用 |
| 区域经理、普通人员 | 不开放本页面和查询/报表接口 | 不可使用 |

数据范围由服务器根据当前登录身份确定，浏览器提交的角色、人员列表或汇总数字不会扩大授权。查询前等待已有业务保存完成，再读取同一服务器数据版本进行计算；筛选不会突破楼长的楼栋范围。切换账号、撤销权限、切换页面或更改期间和筛选条件后，需重新查询生成报表，不能继续导出旧范围结果。

## 管理员配置AI服务

当前已知公网入口为HTTP，真实密钥不要在该入口填写；应先使用HTTPS入口，或在已登录的阿里云HTTPS网页终端中由本人隐藏输入到私有运行配置。当前迁移工具NameError的修复和重试前提见[关系化迁移](13-MySQL关系化存储与迁移.md#2026-11-24-发布入口nameerror修复)，新版发布通过前不要启用旧聊天替代新报表。

1. 使用管理员账号进入 **AI 查询与报表 → AI 服务配置**。
2. 填写服务地址、模型名称和新API Key，按需勾选“启用 AI 解读”。密钥只在管理员配置窗口输入，不要在查询问题、聊天、GitHub、公开文档或截图中传递。
3. 点击 **保存配置**。API Key留空会保留原来保存的密钥；只有勾选“清除服务器已保存的密钥”才清除该文件中的密钥并关闭文件配置的启用开关。更换密钥与清除密钥不能同时选择。
4. 点击 **测试已保存连接**。它测试服务器当前生效的已保存配置，发送不含人员资料的简短测试消息。看到连接测试成功后，再生成实际报表并按需勾选AI解读。

默认接入DeepSeek，服务地址为 `https://api.deepseek.com/chat/completions`，新默认模型为 `deepseek-flash`。这只提供预填值，不能代替有效密钥、模型权限和真实连接测试；已有管理员配置的模型不因默认值更新而覆盖。DeepSeek接口和当前模型说明以[官方Chat Completions文档](https://api-docs.deepseek.com/api/create-chat-completion/)为准。

也可填写其他供应商兼容Chat Completions的完整公网HTTPS接口。当前实现使用非流式文本响应，读取 `choices[0].message.content`，不支持本机或内网HTTP模型地址。接口地址不能包含用户名、密码、查询参数或片段，也不能使用非443端口；服务器校验DNS解析结果并拒绝私网地址及重定向。调用使用服务器固定的有效模型、接口和密钥，不能在查询内容或旧聊天请求中临时指定其他模型或传入密钥。

保存成功与连接成功是两个状态。保存后出现认证失败、额度不足、模型不可用、域名解析或超时错误时，应由管理员核对供应商控制台与服务器网络；错误不会伪装成成功的AI解读，事实统计仍可使用。

### 私有配置与环境覆盖

管理员通过页面保存的设置位于 **`DATA_DIR/ai-settings.json`**，`DATA_DIR`为服务器实际运行数据目录。文件原子写入，权限为 **0600**，由应用运行账号按现有数据权限维护；它不属于公开源码，不通过静态网页开放，也不能提交GitHub。配置读取接口只返回启用状态、是否配置密钥、有效地址、模型和环境覆盖标识，不返回已有密钥。浏览器不再保存API Key、聊天历史或整个人员上下文，并只清理本模块旧版AI存储键。

服务器可通过以下非空环境变量覆盖文件配置；配置页出现环境覆盖提示时，页面保存的值不一定是最终生效值。

| 环境变量 | 作用 |
| --- | --- |
| `HR_AI_ENABLED` | 启用开关，填写 `true` 或 `false` |
| `HR_AI_ENDPOINT` | 完整公网HTTPS Chat Completions接口 |
| `HR_AI_MODEL` | 供应商提供且当前账号可使用的模型名称 |
| `HR_AI_API_KEY` | 由服务器私下配置的密钥 |

环境变量优先于文件配置。页面清除文件密钥不会删除服务环境中的密钥，也不会撤销供应商密钥；如需停用环境配置，应由服务器维护人员调整相应变量并按既有服务流程生效。不要将真实密钥写入公开命令、自述文件或发布清单。

既有管理员“简历分析 / 生成人员简介”功能保留，继续通过固定的同源 **`/api/ai/chat`** 代理调用，使用同一套服务器有效配置，不再让浏览器保存密钥或直连自定义模型地址。该接口仍仅管理员可用，不因楼长开放查询与报表而扩大权限。简历分析会按原流程发送管理员选定的简历文本，与下述仅发送汇总统计的报表解读是两个独立操作。

## 查询与报表生成

**智能查询**：选择期间和可选的楼栋、部门、人员姓名筛选，输入不超过500字的问题，点击“开始查询”。例如“本月已批准的费用加班和调休加班各多少小时？”、“今年考勤记录有多少？”、“请生成本季度报表”。查询文字中明确的年月或季度优先；未指定时使用上方选择的期间。姓名、楼栋和部门仅在已授权数据内匹配。

查询只支持当前实现的人员、考勤、加班、请假和汇总语义。联系方式、薪资金额、跨期对比、修改数据或其他不支持的问题，会明确提示未回答原问题；下方可能仍展示所选期间和筛选条件的事实报表，不能把这份报表当作对原问题的回答。

**期间报表**：功能选择“期间报表”，选月度、季度或年度及对应年月/季度，点击“生成报表”。月报显示1个月，季报显示3个月，年报显示12个月的分月统计；每份结果包含生成时间、数据版本、授权及筛选范围、人员与考勤汇总、加班和请假审批情况、分布、请假原始日期/时分、数据质量提示与统计口径。

报表是用户点击后即时生成。**本次没有新增定时生成、定时发送或自动邮件/月报任务**；已启用的每日数据备份也不等于定时生成经营报表。

### 事实统计与AI解读

未配置密钥、未启用模型或未勾选AI解读时，人员和考勤等数字依然由服务器真实数据计算，可查看与导出；这部分不是模型生成的回答，不会伪造AI分析。

勾选“同时生成 AI 解读”后，服务器仅将本次授权的汇总、分月统计、分布、质量提示和口径发送至管理员配置的模型服务。不会发送原始人员/请假明细、人员姓名、手机号、邮箱、简历或证件附件。AI解读单独显示为辅助说明，不能覆盖表格中的服务器事实数字，也不执行SQL、审批或人员资料变更。

模型连接失败时显示“AI解读失败”及可读原因，已有事实报表保留。模型文字按照纯文本展示，不执行模型返回的HTML；解读中的推断和数值仍需对照事实统计核验。

## 月季年报的统计口径

| 项目 | 当前口径与限制 |
| --- | --- |
| 人员人数、状态、部门和楼栋分布 | 当前授权且筛选后的档案存量，不代表历史月末人数；入职、离职仅按已填且有效的对应日期归属期间 |
| 考勤 | 按实际已有记录统计人次、出勤/迟到/缺勤等状态与去重人数；缺少排班和应出勤基数，不计算出勤率 |
| 加班 | 按发生日期归属；只有最终批准计入费用/调休小时，待楼长、待区域经理、拒绝及异常状态单列，不计入已批准时长 |
| 请假 | 按开始日期一次归属；已批准申请的已记录小时与天数分别汇总，不按8小时互换，也不擅自计算工作日 |
| 跨月、跨季、跨年请假 | 明列原始开始/结束日期及分钟精度；完整已记录时长归属开始期间，不自动摊分；上期开始但与本期重叠的申请单独提示，不重复计入本期开始口径 |
| 月份相加 | 入离职、考勤记录、申请数量及开始口径时长可以按月汇总；当前人员存量、去重考勤人数不能直接累加月份值 |
| 费用 | 费用加班只表示已批准小时，不计算薪资、单价或已结算金额 |
| 历史缺项与异常 | 日期无效、审批阶段或状态异常等进入质量提示；不能把“没有记录”推断成“没有业务” |

请以每份报表随附的统计口径为准。当前权限和档案关联用于限定人员范围，不据此推断历史楼栋归属；更改人员当前楼栋可能影响之后生成报表的范围。

## 导出与打印

生成报表后，在结果上方选择格式，点击“导出当前报表”。

| 格式 | 用途 |
| --- | --- |
| XLSX | Excel工作簿，含服务端统计行、分月数据及口径 |
| CSV | 带中文BOM的表格文本，含分月及明细统计行；公式样式文本作安全处理 |
| JSON | 审阅过的授权事实字段，便于后续数据处理 |
| 独立HTML | 自包含离线报表，含分月、原始请假日期和统计口径，无外部脚本依赖 |
| PDF | 打开可打印HTML预览，通过浏览器“打印 / 另存为 PDF”保存；浏览器拦截时需允许本次打印弹窗 |

导出仅包含本次服务器授权的事实报表，不附带人员简历/证件、密钥或模型原始消息。文本按目标格式转义，CSV/XLSX的公式样式内容不会作为可执行公式。AI解读不代替导出中的事实统计。修改筛选或期间后需重新生成，页面拒绝导出旧条件的报表。
