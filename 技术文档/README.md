## 手机端使用

系统已适配手机屏幕，手机浏览器访问 `http://YOUR_ECS_IP/login.html` 即可使用现有账号密码登录。登录页和主界面已加入 PWA 清单与 Service Worker；在支持安装的浏览器中会显示“安装到手机桌面”。当前公网入口仍为 HTTP，浏览器只有在 HTTPS 域名或 localhost 等安全上下文中才会启用完整的桌面安装和离线能力。

## 阅读顺序

开发人员先阅读 01、02、03；需要处理微信登录或飞书通知时再阅读 04；负责上线和日常管理时阅读 05、06。文档中的命令默认在 Ubuntu 22.04 上以具有 sudo 权限的账号执行。

## 重要约定

1. `server/config.json` 含有服务端配置，App Secret 等敏感字段不能提交到前端、浏览器、截图或公共代码仓库。
2. 发布代码时必须先备份 `server/data` 和 `server/config.json`，再覆盖程序文件。
3. 公网只开放 80；8080 是应用内端口，不应直接暴露给互联网。
4. 当前系统使用 JSON 快照保存业务数据，不能按传统数据库的方式直接并发写入同一条记录。
