## 内容与适用范围

使用篇介绍三种角色、手机号注册登录、我的资料、人员工号及新增展示信息、楼长授权与更换、加班请假申请和自己的小时数。设施运维主管可由管理员按楼长角色授权：先注册，管理员在“系统设置 → 权限管理”关联档案、指定“楼长”及负责楼栋；岗位名称本身不授予权限。调整或撤销旧账号授权后，看板下次读取自动显示新名单，退出登录不会撤销楼长任命。

技术篇介绍原生 HTML/CSS/JavaScript、SheetJS、Node.js 内置 HTTP 服务、`mysql2`、MySQL 快照及受保护 JSON、Nginx、systemd，以及本地启动、测试、备份发布、验收和恢复。版本来自项目公开代码与已有验收文档，当前部署版本是项目参考环境，不作为最新版本选型建议。

画面为操作示意动画，使用“演示人员 A”等虚构资料，不是真实生产录屏。视频不构成真实人员名单、权限或数据的验收记录。生产已发布工号与楼长自动名单；短信验证码仍为已开发、默认关闭且未部署启用。飞书消息和 AI 等扩展需单独配置。业务能力与权限详情见[手机号账号与数据权限](../../技术文档/07-手机号账号与数据权限.md)，部署命令见[阿里云部署手册](../../技术文档/05-阿里云部署手册.md)。

## 后续维护

制作入口为项目根目录的 `scripts/video/render-scenes.ps1`、`scripts/video/synthesize-narration.ps1` 和 `scripts/video/build-video.py`。工具使用公开分镜、本机 Windows 语音和 FFmpeg，不读取生产配置、账号文件或真实人员数据。

在 Windows 上准备好本机 Windows PowerShell、`Microsoft Huihui Desktop` 语音、微软雅黑、Python 3，以及可在命令行使用的 `ffmpeg` 和 `ffprobe`。从项目根目录依次执行以下三步，中间音频、场景图与编码片段存入 `.delivery/video-build`，不会作为公开交付文件上传。

1. 生成本地中文旁白：

   ```powershell
   powershell.exe -NoProfile -File scripts/video/synthesize-narration.ps1 -StoryboardPath "视频/人力资源管理系统使用与技术介绍/分镜脚本.json" -OutputDir ".delivery/video-build/audio" -Rate 5
   ```

2. 绘制 24 个场景及预览联系表：

   ```powershell
   powershell.exe -NoProfile -File scripts/video/render-scenes.ps1 -StoryboardPath "视频/人力资源管理系统使用与技术介绍/分镜脚本.json" -OutputDir ".delivery/video-build/frames" -ContactSheetPath ".delivery/video-build/contact-sheet.png"
   ```

3. 合成主视频、字幕、章节播放器及视频信息，并执行全片解码检查：

   ```powershell
   python scripts/video/build-video.py --work ".delivery/video-build" --output "视频/人力资源管理系统使用与技术介绍"
   ```

相同分镜在不同语音版本或工具环境下重新制作，时长和文件摘要可能变化，应以新生成的 `视频信息.json` 为准。修改画面或旁白后须重新编码，不应沿用旧片段。

功能变化时先核对分镜中的操作、权限、生产与开发边界，再重新生成配音、画面、字幕和视频信息，检查视频完整性与文字可读性，并更新当日自述、`updates` 及固定架构 HTML。重新制作需保留同一组交付文件名，避免播放器与媒体版本混用。
