# 05 阿里云 ECS 部署手册

## 1. 当前生产环境

| 项目 | 参考值（当前部署示例） |
|---|---|
| ECS 公网 IP | `YOUR_ECS_IP` |
| OS | Ubuntu 22.04 LTS |
| Node.js | v20.20.2（当前部署参考） |
| npm | 10.8.2 |
| Nginx | 1.18.0（Ubuntu） |
| MySQL | 8.0.46（当前部署参考，仅监听本机） |
| 应用目录 | `/opt/hr-system` |
| 应用用户 | `hrsystem` |
| Node 监听 | `0.0.0.0:8080` |
| 对外入口 | `http://YOUR_ECS_IP:80` |
| systemd | `hr-system.service` |

## 2. 端口和访问路径

```text
客户端 -> TCP 80 -> Nginx -> 127.0.0.1:8080 -> Node.js
```

安全组建议：

| 端口 | 来源 | 用途 |
|---|---|---|
| TCP 22 | 管理员固定公网 IP | SSH 运维 |
| TCP 80 | `0.0.0.0/0` 或企业出口 IP | 网站访问 |
| TCP 443 | 配置 HTTPS 后开放 | HTTPS 访问 |
| TCP 8080 | 不开放公网 | Node 内部端口 |

示例入口使用 HTTP。公开部署应接入域名、申请证书并改成 HTTPS；微信登录回调域名和飞书消息服务也应改为 HTTPS 域名。

## 2.1 手机端访问与安装

手机直接打开 `http://YOUR_ECS_IP/login.html`，使用系统现有账号密码登录即可。页面已采用响应式布局，侧边栏会切换为手机抽屉菜单。登录页会在浏览器支持时显示“安装到手机桌面”，安装后从桌面图标进入仍会先经过登录页。

完整 PWA 安装需要 HTTPS 安全上下文；接入域名证书后，将 Nginx 的 443 请求反向代理到同一个 Node 端口即可，无需增加手机客户端服务器。

## 3. 新服务器安装环境

以下命令适用于 Ubuntu 22.04：

```bash
sudo apt update
sudo apt install -y unzip curl nginx mysql-server

# 安装 Node.js 20 LTS（NodeSource）
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

node --version
npm --version
nginx -v
mysql --version
```

安装完成后应看到与当前参考部署接近的 Node.js 20.x、npm 10.x 和 Nginx 1.18.x；这些版本是现有部署示例，不代表最新版推荐。

## 4. 部署目录和用户

```bash
sudo useradd --system --home /opt/hr-system --shell /usr/sbin/nologin hrsystem || true
sudo mkdir -p /opt/hr-system
sudo chown -R hrsystem:hrsystem /opt/hr-system
```

将源码包解压到 `/opt/hr-system`。确保目录中包含 `index.html`、`login.html`、`js/`、`css/` 和 `server/server.js`。

## 5. systemd 服务

创建 `/etc/systemd/system/hr-system.service`：

```ini
[Unit]
Description=HR Personnel Management System
After=network.target

[Service]
Type=simple
User=hrsystem
Group=hrsystem
WorkingDirectory=/opt/hr-system
ExecStart=/usr/bin/node /opt/hr-system/server/server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

启用并启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable hr-system.service
sudo systemctl start hr-system.service
sudo systemctl status hr-system.service --no-pager
```

## 6. Nginx 反向代理

创建 `/etc/nginx/sites-available/hr-system`：

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name YOUR_ECS_IP;

    client_max_body_size 10m;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置：

```bash
sudo ln -sfn /etc/nginx/sites-available/hr-system /etc/nginx/sites-enabled/hr-system
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
```

## 7. 发布更新流程

在开发机生成 zip 后上传到服务器。发布时不要覆盖线上数据和配置：

```bash
scp hr-system-deploy.zip root@YOUR_ECS_IP:/tmp/hr-system-deploy.zip
ssh root@YOUR_ECS_IP

set -e
rm -rf /tmp/hr-data-backup /tmp/hr-config-backup.json
cp -a /opt/hr-system/server/data /tmp/hr-data-backup
cp -a /opt/hr-system/server/config.json /tmp/hr-config-backup.json
unzip -q -o /tmp/hr-system-deploy.zip -d /opt/hr-system
rm -rf /opt/hr-system/server/data
mv /tmp/hr-data-backup /opt/hr-system/server/data
mv /tmp/hr-config-backup.json /opt/hr-system/server/config.json
chown -R hrsystem:hrsystem /opt/hr-system
chmod 600 /opt/hr-system/server/config.json
systemctl restart hr-system.service
systemctl reload nginx
```

如果发布包只包含代码，也可以省略解压后恢复配置的步骤；生产上仍建议每次先备份。

## 8. 发布后验证

服务器内验证：

```bash
systemctl is-active hr-system.service
systemctl is-active mysql
curl -I http://127.0.0.1:8080/
curl -sS http://127.0.0.1:8080/api/feishu/login-config
ss -ltnp | grep -E ':80|:8080'
```

公网验证：

```bash
curl -I http://YOUR_ECS_IP/
curl -sS http://YOUR_ECS_IP/api/feishu/login-config
```

浏览器验证登录页、普通账号登录、微信扫码登录（配置凭据后）、看板、人员数据和请假/加班页面。发布后若页面仍旧，使用 Ctrl+F5 或检查 `index.html` 的脚本版本参数。

MySQL 数据验证：

```bash
mysql --protocol=socket -uroot -e "SELECT table_name FROM information_schema.tables WHERE table_schema='hr_system';"
curl -sS http://127.0.0.1:8080/api/data/snapshot.json | python3 -c "import json,sys; print(len(json.load(sys.stdin)['employees']))"
```

## 9. 回滚

发布前保存代码包、`server/data` 和 `server/config.json`。回滚时停止服务，恢复上一版代码和这两个备份，再启动服务并执行内外网健康检查。不要只回滚前端文件而保留不兼容的数据结构。
