# 华北一部酒仙桥人力资源管理平台

最新自述与更新：[2026-11-13.md](2026-11-13.md)。

可视化架构文档：[人力资源管理系统开发架构.html](人力资源管理系统开发架构.html)，可直接离线打开，展示架构、技术栈、权限、数据流和部署流程。每次项目更新后同步生成到同一文件，维护方法见 [08-架构HTML维护](技术文档/08-架构HTML维护.md)。

一套面向人力资源和运营团队的人员管理系统，覆盖人员档案、组织架构、考勤、加班、请假、调休、费用结算、数据看板和系统管理。

## 功能

- 人员主数据：人员档案、选填工号、楼栋、部门、邮箱、入离职日期、岗位、状态、附件和导入导出
- 考勤管理：出勤记录、加班申请、请假申请、审批状态和历史查询
- 加班与调休：费用加班和调休加班分开计算，展示总时长与剩余时长
- 费用结算：保留加班和请假费用结算，不提供人员薪资结算
- 数据看板：楼栋人数、人员变化、调休时长和月度业务汇总
- 组织与权限：组织架构、账号管理、管理员与普通用户权限
- 账号：手机号注册与密码登录，注册同步建立人员档案，支持个人资料维护
- 验证码：已开发手机号注册、密码登录加短信验证码；短信服务配置后启用，当前默认关闭
- 权限：管理员查看全部，楼长只查看负责楼栋，普通人员仅查看自己的资料、申请和小时数
- 第三方集成：保留飞书消息通知；微信、飞书登录均已取消
- 表单与楼栋配置：真实下拉选项、空楼栋和楼长显示保存在独立服务端组织配置中，不随公开代码覆盖
- 手机端：响应式页面、手机抽屉菜单、PWA 清单和 Service Worker

## 技术栈

### 前端

- HTML5、CSS3、原生 JavaScript
- Fetch API、服务端 Cookie 会话与内存中的个人范围数据
- CSS Grid/Flexbox 响应式布局
- SheetJS 用于表格导入导出

### 后端

- Node.js 20 LTS
- Node 内置 `http`、`fs`、`crypto` 和 `fetch`
- `mysql2` 连接 MySQL 8
- Nginx 反向代理，systemd 管理服务

### 数据

业务数据通过 `/api/data/snapshot.json` 以快照方式同步。生产环境使用 MySQL `hr_system` 数据库的 `system_snapshots` 表作为主存储，同时保留 JSON 快照作为初始化和灾备副本。

## 本地运行

1. 安装 Node.js 20 LTS。
2. 复制配置模板：

   ```powershell
   Copy-Item server/config.example.json server/config.json
   ```

3. 在 `server/config.json` 中填写需要启用的服务端配置。开发环境可以保持 MySQL 和第三方登录关闭。
4. 安装后端依赖并启动：

   ```powershell
   cd server
   npm install
   node server.js
   ```

5. 浏览器打开 `http://localhost:8080/login.html`。

首次运行时，在服务器本机打开登录页，点击“首次使用：初始化管理员”，设置至少 12 位的管理员密码。普通人员通过“手机号注册”填写人员表单并设置至少 8 位密码。短信验证码功能已开发，默认关闭；开通短信服务并启用后，手机号注册和登录均须正确验证码，登录仍需密码。账号和密码哈希保存在服务端，支持换设备登录。详细权限见 [`技术文档/07-手机号账号与数据权限.md`](技术文档/07-手机号账号与数据权限.md)，短信配置见 [`技术文档/09-短信验证码接入.md`](技术文档/09-短信验证码接入.md)。

## 阿里云部署

当前生产环境采用以下结构：

```text
手机或电脑 -> Nginx:80/443 -> Node.js:8080 -> MySQL:127.0.0.1:3306
```

| 项目 | 环境 |
|---|---|
| 操作系统 | Ubuntu 22.04 LTS |
| Node.js | 20.20.2 |
| npm | 10.8.2 |
| Nginx | 1.18.0 |
| MySQL | 8.0.46，仅监听 127.0.0.1 |
| 应用目录 | `/opt/hr-system` |
| systemd 服务 | `hr-system.service` |
| 应用用户 | `hrsystem` |

公网只开放 80/443 和受限 SSH 22，8080 与 3306 不应直接暴露公网。详细命令见 [`技术文档/05-阿里云部署手册.md`](技术文档/05-阿里云部署手册.md)。

本次工号更新使用 [`deploy/apply-personnel-fields.py`](deploy/apply-personnel-fields.py) 定向发布，须与同目录的 `apply-organization-fix.py` 一起提供，并预先核对现网认证服务的规范化 SHA-256。仅安装三份人员前端 JS、固定架构 HTML 和现网认证服务的三处补丁，保留账号、组织配置和业务数据，不部署短信开发版。备份、验收与恢复步骤见部署手册的“工号定向发布”；历史固定版本 `aliyun-2026-11-11.sh` 不用于本次更新。架构 HTML 仍可离线打开，安装到服务器不等于已开放公网访问。

工号生产版本固定为 `682e2e26a200729ddab9225f67a6cd2b6aaa8894`：用户报告服务器脚本返回 `PERSONNEL_FIELDS_OK`，独立公网核对确认三份前端文件与发布版本逐字节一致，公开接口及匿名访问边界正常。后续验收记录及 HTML 仅更新本地和 GitHub，服务器 HTML 仍为固定发布版本；短信开发版未部署。证据范围见 [当日更新](updates/2026-11-13.md)。

## 手机访问

手机浏览器打开：

```text
http://YOUR_ECS_IP/login.html
```

当前系统可以直接在手机浏览器登录。完整的“安装到手机桌面”弹窗和离线能力需要 HTTPS 域名；HTTP 地址可以通过浏览器菜单选择“添加到主屏幕”。

## 配置安全

这是面向 Public 仓库的脱敏源码包，已移除生产人员快照、凭据、默认密码、内部网络地址、楼栋负责人姓名和业务 Excel 模板。部署方请在自己的环境中补充组织架构和数据；Excel 模板可在系统内生成。

以下文件只提供模板或通过 `.gitignore` 排除，禁止提交真实凭据和生产数据：

- `server/config.json`
- `server/data/snapshot.json`
- 实际数据目录的 `organization-settings.json`、`auth-users.json` 与恢复副本
- MySQL 环境变量文件
- 微信 AppSecret、飞书 AppSecret、SSH 密码

生产配置请放在服务器受限文件中，或通过 systemd `EnvironmentFile` 注入。人员快照属于业务数据，不上传到公开仓库。
